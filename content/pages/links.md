## Para leer y explorar

- [Biblioteca Digital Hispánica](https://www.bne.es/es/catalogos/biblioteca-digital-hispanica) — Un punto de partida para buscar documentos y libros.
- [Project Gutenberg](https://www.gutenberg.org/) — Explorar ediciones digitales y sus condiciones de uso.
- [Wikimedia Commons](https://commons.wikimedia.org/) — Recursos visuales; revisá siempre la licencia de cada archivo.

## Para construir un sitio propio

- [GitHub Pages](https://pages.github.com/) — Publicar archivos estáticos.
- [MDN Web Docs](https://developer.mozilla.org/es/) — Consultar HTML, CSS y JavaScript.
- [RSS](https://www.rssboard.org/rss-specification) — Leer la especificación del formato del feed.

No son servicios integrados. Son enlaces externos, elegidos para mostrar una página de curaduría.
