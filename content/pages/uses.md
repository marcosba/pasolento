## Para escribir

Un editor de texto sencillo, archivos Markdown y una libreta que ya estaba en casa. Lo importante es poder empezar y poder llevarse el contenido.

## Para leer

Libros de papel y un lector digital cuando el viaje pide menos peso. Un señalador antes que una aplicación nueva.

## Para caminar

Calzado adecuado, agua, una capa extra, protección del sol y la información actualizada del lugar. La lista cambia con el clima y la dificultad; no es una guía completa de equipamiento.

## Para este sitio

HTML, CSS, JavaScript y un generador pequeño en Python. Fuentes e imágenes locales. GitHub Pages como destino de publicación. Más detalles en el [colofón](site:colophon/).
