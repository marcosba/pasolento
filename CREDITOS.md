# Recursos y créditos

## Diseño y contenido

El proyecto usa una capa editorial propia sobre una adaptación de la hoja CSS suministrada con la solicitud. Se sustituyeron sus recursos externos por iconos locales y se retiraron los enlaces de captura ajenos al sitio.

La hoja CSS aportada no incluye una licencia original verificable. Si proviene de un tercero, comprobá que tenés derecho a reutilizarla antes de publicar. No se declara una licencia global para ese material.

La identidad «Alex Ríos», los relatos y las cifras de recorrido son de demostración. No representan a una persona real. Los nombres de obras, autores, músicos y cineastas pertenecen a sus respectivos titulares.

## Tipografías

- **Lora**: distribuida bajo SIL Open Font License 1.1. Archivo: `assets/fonts/OFL-lora.txt`.
- **DM Sans**: distribuida bajo SIL Open Font License 1.1. Archivo: `assets/fonts/OFL-dmsans.txt`.

Los archivos de las fuentes se incluyen localmente, sin llamadas a servicios externos durante una visita.

## Imágenes e iconos

- Paisaje patagónico, escena de lectura y calle de Buenos Aires: ilustraciones generadas para este proyecto. No son fotografías documentales.
- Cubiertas de libros, discos, películas y series: diseños geométricos originales creados como ilustraciones para la demo. No reproducen portadas oficiales.
- Iconos: trazados SVG locales incluidos en `tools/prepare_assets.py`.

La política de transparencia del sitio está en `/ai/`.
